Bedrock notes app v0.1.2: Bedrock no longer runs in the background.

**Changed**
- Closing the window quits Bedrock on every computer, Mac included. Sync and agent access stop when it quits.
- No tray or menu bar icon.
- Bedrock never starts at login, and it removes any login item an earlier version left behind.
- The hub's "hide" now minimizes the window instead of hiding it, and Bedrock always opens with its window showing.

**Parity with Obsidian:** 620 of 669 items in docs/FEATURES.md are done, including 5 marked not applicable (Publish and the mobile app). Unchanged from v0.1.1.
