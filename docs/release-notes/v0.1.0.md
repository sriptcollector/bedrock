First release of the Bedrock notes app (Bedrock by Toolbay): a free, open-source notes app that works with your Obsidian vaults, with sync built in.

**What's in it**
- The Obsidian look and layout: file explorer, tabs, stacked tabs, splits, popout windows, sidebars, ribbon, status bar, light and dark themes. Community themes and CSS snippets work.
- Editor: Live Preview, source mode and reading view, with editable tables, callouts, embeds, properties, math, Mermaid, footnotes, folding and Vim mode. In a side-by-side harness 357 of 358 editor behaviours match Obsidian 1.14.
- Search with the full query language, backlinks, outgoing links, tags, outline, bookmarks, graph view and local graph, Canvas (JSON Canvas), Bases tables and cards, daily notes, templates, web viewer and slides.
- All 227 Obsidian command ids and the default hotkeys, so your hotkeys.json keeps working.
- Community plugins and themes: browse and install from inside the app. 14 of the 15 popular plugins we tested fully work (see docs/PLUGINS.md).
- Sync through your Toolbay account: one vault, end-to-end encrypted, version history, recycle bin and conflict handling, with no setup. It turns on when you're signed in to the Toolbay app and the sync service is live. Until then Bedrock works fully on its own.
- Agent access: an MCP server, a local REST API and a `bedrock` command, plus one-click setup for Claude Code, Claude Desktop and Cursor (Settings › Connect an AI agent).

**Parity with Obsidian:** 620 of 669 items in docs/FEATURES.md are done, including 5 marked not applicable (Publish and the mobile app).

**Known gaps:** a pdf.js toolbar for PDFs, interface languages other than English, a few settings-page row orders, and the items left unchecked in docs/FEATURES.md.
